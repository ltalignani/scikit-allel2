``scikit-allel2``
=================

A Python package for exploratory analysis of large scale genetic variation data.

scikit-allel2 continues `scikit-allel <https://github.com/cggh/scikit-allel>`__
for Python 3.12+, NumPy 2, zarr 3 and pandas 3. Existing code only needs to
change its import::

    import allel2 as allel

See `Migrating from scikit-allel
<https://scikit-allel2.readthedocs.io/en/latest/migrating.html>`__.

* Documentation: https://scikit-allel2.readthedocs.io/
* Source code: https://github.com/ltalignani/scikit-allel2
* Download: https://pypi.org/project/scikit-allel2/

Installation
************

scikit-allel2 requires Python 3.12 or later, on Linux or macOS::

    pip install scikit-allel2

To cite scikit-allel2, please cite scikit-allel:
